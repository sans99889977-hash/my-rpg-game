# RPG Adventure (เว็บไซต์เกม)

## วิธีเปิดเล่น
1. แตกไฟล์ ZIP นี้
2. เปิดไฟล์ `index.html` ด้วย Chrome, Safari, Firefox หรือ Edge
3. สร้างตัวละครและเริ่มเล่นได้เลย

เกมบันทึกความคืบหน้าไว้ใน Local Storage ของเบราว์เซอร์เครื่องนั้น

## วิธีนำขึ้นออนไลน์
อัปโหลดไฟล์ `index.html` ไปยังบริการโฮสต์เว็บแบบ Static เช่น GitHub Pages, Netlify หรือ Cloudflare Pages แล้วใช้ URL ที่ได้เข้าเล่น

## หมายเหตุเกี่ยวกับฟีเจอร์ออนไลน์
ระบบเกมหลักและเซฟในเบราว์เซอร์ทำงานแบบ standalone ได้ ส่วนการซิงก์เซฟข้ามอุปกรณ์, ปาร์ตี้/ผู้เล่นออนไลน์, กิลด์ และบทสนทนา AI อาศัย API ของสภาพแวดล้อม Claude ที่อยู่ในโค้ดต้นฉบับ จึงอาจไม่ทำงานเมื่อโฮสต์เป็นเว็บทั่วไปโดยไม่มี backend และการเชื่อมต่อดังกล่าว
